# AI-Powered-Research-Paper-Summarizer-Insight-Extractor🤖📄
Agile Documents - https://docs.google.com/spreadsheets/d/1ntHsxz1vgYnJU5ejdUnEZ8NpWPv98Zyr/edit?usp=sharing&ouid=104885416843608628685&rtpof=true&sd=true


An intelligent tool designed to process, analyze, and summarize complex research papers using Natural Language Processing (NLP) and Vector Databases. This project helps researchers quickly extract key insights from dense academic PDFs.

---

## 🚀 Features
* **PDF Processing:** Automatically extracts and cleans text from research papers.
* **Smart Summarization:** Generates concise, context-aware summaries of long documents.
* **Vector Search:** Uses a local Vector DB for efficient information retrieval and "Chat with PDF" capabilities.
* **Organized Workflow:** Clean separation of data, scripts, and evaluation notes.

---

## 📁 Project Structure
The repository is organized to ensure scalability and clarity:
* `app.py`: The main entry point for the application.
* `scripts/`: Contains the core Python logic for PDF parsing and AI summarization.
* `data/`: Directory for input research papers (PDFs).
* `vector_db/`: Local storage for vector embeddings and database indexes.
* `evaluation_notes.txt`: Performance metrics and testing observations.
* `LICENSE`: MIT License for open-source use.
